## 核心概念 ★

### 线性代数:数据 = 矩阵,变换 = 矩阵乘法

在 AI 里,几乎所有数据都是**张量**(Tensor):

| 概念 | 数学 | 代码(numpy) | 例子 |
|------|------|-------------|------|
| 标量 | $x \in \mathbb{R}$ | `x = 3.0` | 一个损失值 |
| 向量 | $\mathbf{x} \in \mathbb{R}^n$ | `x = np.array([1,2,3])` | 一个词向量 |
| 矩阵 | $\mathbf{X} \in \mathbb{R}^{m \times n}$ | `X.shape = (4,3)` | 一批样本,4 条每条 3 特征 |
| 张量 | $\mathbf{X} \in \mathbb{R}^{...}$ | `X.shape = (B, C, H, W)` | 一批图片 |

矩阵乘法是核心运算,它本质是**线性变换的复合**:

$$
\mathbf{y} = \mathbf{W}\mathbf{x} + \mathbf{b}
$$

这就是神经网络一层的全部数学 —— 一个线性变换 + 一个偏移。

### 概率论:用分布表达不确定性

| 概念 | 公式 | 直觉 |
|------|------|------|
| 期望 | $E[X] = \sum x \cdot p(x)$ | 加权平均(重心) |
| 方差 | $\text{Var}(X) = E[(X-\mu)^2]$ | 离散程度 |
| 贝叶斯 | $P(A\|B) = \frac{P(B\|A)P(A)}{P(B)}$ | 看到证据后更新信念 |

交叉熵是分类损失的数学根源:

$$
L = -\sum_{i} y_i \log \hat{y}_i
$$

> ✅ **思考一下**:如果预测 $\hat{y}$ 和真实 $y$ 完全一致,交叉熵等于多少?(提示:$y$ 是 one-hot)

### 微积分:导数 = 变化率,梯度 = 多维变化率

导数告诉我们函数**局部怎么变化**:

$$
f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}
$$

链式法则(chain rule)是反向传播的数学基础 —— 复合函数的导数 = 各级导数相乘:

$$
\frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)
$$

> ✅ **思考一下**:$f(x) = \sin(x^2)$ 的导数是什么?(用链式法则)

### 优化:梯度下降

梯度 $\nabla L$ 指向函数**上升最快**的方向,所以我们要**减去**它:

$$
\theta \leftarrow \theta - \eta \cdot \nabla L(\theta)
$$

其中 $\eta$ 是学习率(步长)。这就是整个深度学习训练的核心公式。

## 为什么这样设计

### 为什么矩阵乘法能表示「一层神经网络」?

因为神经网络层做的事就是:把输入**旋转拉伸**(线性变换 $\mathbf{W}$)+ **平移**(偏置 $\mathbf{b}$)+ **弯曲**(激活函数)。前两步合起来就是矩阵乘法,极其高效(GPU 擅长大规模矩阵运算)。

### 为什么梯度指向上升最快方向?

这是**方向导数**的结论:函数在某方向的变化率 = 梯度在该方向的投影。要让变化率最大,方向应与梯度同向。

| 对比 | 全局最优 | 局部最优 |
|------|---------|---------|
| 凸函数 | 梯度下降必能找到 | = 全局最优 |
| 非凸函数(神经网络) | 不保证找到 | 可能困在局部 |

## 代码:最小实现

下面三段代码可以直接跑。打开 [JupyterLite](https://jupyterlite.github.io/demo/) 粘贴试运行。

**① 矩阵 = 线性变换**

```python
import numpy as np

A = np.array([[1, 0], [0, -1]])   # y 轴翻转
B = np.array([[0, -1], [1, 0]])   # 旋转 90°
v = np.array([1, 2])

print('原向量:', v)
print('A·v (y翻转):', A @ v)       # [1, -2]
print('B·v (转90°):', B @ v)        # [-2, 1]
print('特征值 A:', np.linalg.eigvals(A))  # [1, -1] → 一个方向翻转
```

**② 梯度下降求最小值**

```python
# 求 f(x) = x² 的最小值,真解是 0
x = 3.0           # 起始点
lr = 0.1          # 学习率 η
for step in range(15):
    grad = 2 * x  # ∇L = d(x²)/dx = 2x
    x = x - lr * grad
    print(f'step {step:2d}: x={x:6.4f}  loss={x*x:8.6f}')
# 最终 x ≈ 0,收敛!
```

**③ 链式法则:手动反向传播**

```python
# f(x) = sin(x²),求 f'(2)
# 链式: f'(x) = cos(x²) · 2x
x = 2.0
df = np.cos(x**2) * 2 * x
print(f"f'(2) = {df:.4f}")  # 数值验证
h = 1e-6
print(f"数值导数 = {(np.sin((x+h)**2) - np.sin(x**2))/h:.4f}")
```

## ⚠️ 易错点 / 面试陷阱

> **陷阱 1**:梯度指向**上升**方向,更新时要**减**($\theta - \eta \nabla L$),不是加!面试常考这个符号。

> **陷阱 2**:学习率太大→发散震荡,太小→收敛极慢。没有「万能学习率」,要调。

> **陷阱 3**:矩阵乘法形状要匹配:$\mathbf{A}_{m \times n} \cdot \mathbf{B}_{n \times p} = \mathbf{C}_{m \times p}$。`A @ B` 里 A 的列数必须等于 B 的行数。
