# 第 1 阶段 · 数学与编程基础

> 目标:能手算梯度、用 numpy 写出基本算法。这是所有后续阶段的「地基」。

## 这个阶段解决什么

很多人想直接跳到大模型,结果卡在「为什么这样更新参数」「矩阵为什么这么乘」。本阶段补齐**够用的**数学 + 编程地基,不追求数学家水平,只追求「看得懂论文公式、写得出实现」。

## 学习目标

- [ ] 看懂梯度、链式法则,能手算简单函数的导数
- [ ] 理解矩阵乘法 = 线性变换,能写 numpy 实现
- [ ] 掌握概率分布、期望方差、贝叶斯的基本直觉
- [ ] 会用 Python + numpy 做数据处理
- [ ] 说出监督 / 无监督 / 自监督的区别
