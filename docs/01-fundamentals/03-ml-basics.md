## 这节解决什么问题

大模型本质也是机器学习。如果你分不清监督和无监督、不懂过拟合、不知道数据怎么划分,后面的训练、微调、评测全是空中楼阁。本节建立 ML 的全局框架,让后面所有阶段都有参照系。

## 核心概念 ★

### 四种学习范式

| 范式 | 数据 | 目标 | 例子 | 大模型中的应用 |
|------|------|------|------|----------------|
| **监督** | $X \to Y$(有标签) | 学 $X \to Y$ 映射 | 分类、回归 | SFT(指令-回答对) |
| **无监督** | 只有 $X$ | 找结构 | 聚类、降维 | 预训练词向量 |
| **自监督** | 从 $X$ 造标签 | 学表示 | MLM、对比学习 | **预训练**(预测下一个 token) |
| **强化** | 状态-动作-奖励 | 学策略 | 游戏、机器人 | **RLHF 对齐** |

> ✅ **思考一下**:GPT 预训练时「预测下一个 token」属于哪种范式?(答案:自监督 —— 标签从数据自身构造)

### 核心目标:泛化

机器学习的终极目标**不是**在训练集上表现好,而是**泛化**到未见过的数据:

$$
\text{泛化误差} \approx \text{训练误差} + \text{复杂度带来的间隙}
$$

### 偏差-方差权衡

| 现象 | 原因 | 表现 | 对策 |
|------|------|------|------|
| **欠拟合**(高偏差) | 模型太简单 | 训练集都差 | 加特征 / 加容量 / 训久点 |
| **过拟合**(高方差) | 模型太复杂 | 训练好测试差 | 加数据 / 正则 / Dropout |
| 噪声 | 数据本身有错 | 误差下限 | 清洗数据 |

### 数据集三划分

$$
\underbrace{\text{训练集}}_{\text{学参数}} \quad \underbrace{\text{验证集}}_{\text{调超参}} \quad \underbrace{\text{测试集}}_{\text{只看一次}}
$$

> ⚠️ 验证集可以反复用(调参),测试集**只在最后评估一次**。用测试集训超参 = 数据泄漏。

### 评估指标

| 任务类型 | 常用指标 | 直觉 |
|----------|----------|------|
| 二分类 | 准确率、精确率、召回率、F1、AUC | 平衡查准和查全 |
| 多分类 | 准确率、混淆矩阵 | 哪类容易混 |
| 回归 | MAE、MSE、RMSE、$R^2$ | 预测值离真值多远 |

## 为什么这样设计

### 为什么自监督能火?

因为标注数据太贵。自监督从海量**无标注**数据里自动构造监督信号(如「盖住一个词,预测它是什么」),让模型用上整个互联网的文本。这是 GPT/BERT 成功的关键 —— **用数据规模换标注成本**。

### 为什么过拟合是「测试差训练好」?

模型把训练集里的**噪声和偶然规律**也背下来了,这些东西在新数据上不存在,所以泛化差。就像学生背了题库答案但不会举一反三。

| 对比 | 过拟合 | 欠拟合 |
|------|--------|--------|
| 训练误差 | 低 | 高 |
| 测试误差 | 高 | 高 |
| 模型复杂度 | 过高 | 过低 |
| 类比 | 死记硬背 | 根本没学 |

## 代码:最小实现

**① 手写 KNN:最直观的监督学习**

```python
import numpy as np

def knn(X_train, y_train, x_test, k=3):
    """最简单的监督学习:找最近的 k 个邻居投票"""
    d = np.sum((X_train - x_test) ** 2, axis=1)  # 欧氏距离(向量化!)
    idx = np.argsort(d)[:k]                       # 最近的 k 个
    return np.bincount(y_train[idx]).argmax()     # 多数投票

# 玩具数据:4 个点,两类
X = np.array([[1, 1], [1.5, 1.8], [5, 5], [6, 5.5]])
y = np.array([0, 0, 1, 1])                        # 0=A 类, 1=B 类

print('点 [2,2] 预测:', knn(X, y, [2,2]))        # 应为 0(A 类)
print('点 [5.5,5] 预测:', knn(X, y, [5.5,5]))    # 应为 1(B 类)
```

**② 直观体会过拟合:k 的大小**

```python
# 把 k 改成 1,看看会发生什么
print('k=1 时 [2,2] 预测:', knn(X, y, [2,2], k=1))
# k=1 极度敏感 → 过拟合倾向
# k 太大 → 太迟钝 → 欠拟合
```

**③ 简单的交叉验证思路**

```python
# 把数据分成 train / val / test
np.random.seed(42)
idx = np.random.permutation(100)
train_idx, val_idx, test_idx = idx[:60], idx[60:80], idx[80:]
# 用 train 训练, val 选 k, test 只在最后报告一次结果
print(f'训练 {len(train_idx)} / 验证 {len(val_idx)} / 测试 {len(test_idx)}')
```

## ⚠️ 易错点 / 面试陷阱

> **陷阱 1**:测试集**只能看一次**。用测试集选模型/调超参 = 数据泄漏,结果会虚高。面试必问。

> **陷阱 2**:类别不平衡时,**准确率会骗人**。99 个负样本 + 1 个正样本,全预测负样本准确率 99%,但毫无用处。这种情况看 F1 / AUC。

> **陷阱 3**:「准确率」vs「精确率」别混 —— 准确率 = 对的比例;精确率 = 预测为正里真正为正的比例。 Recall = 真正为正里被找出来的比例。

**课前小测答案:**

1. **无监督学习**(聚类,如 K-Means)。没有标签,目标是「找结构」。
2. **过拟合**。训练集表现远好于测试集 = 模型背了训练集的噪声,泛化不了。对策:加数据 / 正则 / 简化模型 / Dropout。
3. 因为一旦你看了测试集结果并据此调整模型,测试集就**污染**了(变成了验证集)。测试集代表「真实世界的未知数据」,必须保持干净,只在最后报告一次。
