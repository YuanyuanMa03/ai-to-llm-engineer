## 模板设计说明

| 板块 | 来源 | 作用 |
|------|------|------|
| 课前小测 | 微软 | 激活先验知识,让学习有针对性 |
| 核心概念 + ✅思考框 | 我们 + 微软 | 公式严谨 + 苏格拉底提问 |
| 对比表格 | 微软 | 用二元对立框定概念 |
| 代码最小实现 | 我们 | 可跑,不只贴伪代码 |
| ⚠️ 易错点 | 我们 | 面试官爱挖的坑 |
| 🎯 面试会怎么考 | **我们独有** | 八股 + 手撕 + 深挖,求职导向 |
| 📂 简历项目 | **我们独有** | 把知识变成求职弹药 |
| 🚀 挑战 | 微软 | 开放任务,鼓励动手 |
| 课后小测 | 微软 | 前后测闭环,检验掌握 |
