# AI 手帐 · 从小白到大模型算法工程师

> 一份**求职导向**的大模型算法工程师学习路线图。每一节不只是讲「是什么」,更点明「**面试会怎么考、简历能写什么项目**」。

## ✨ 这是什么

一个把**手帐笔记本**质感和**求职路线图**结合的中文教程。覆盖从数学基础到大模型部署的全链路 5 个阶段:

```
数学 & 编程基础 → 深度学习 & Transformer → 预训练 → 微调 & 对齐 → 应用 & 部署
```

## 🎯 适合谁

- 想转行成为**大模型算法工程师**的小白
- 准备 AI 算法岗**面试**的应届生 / 在校生
- 想系统补齐 LLM 知识体系的工程师

## 📚 内容结构

15 篇正文 · 5 个阶段 · 每篇含课前课后测、可跑代码、面试考点、简历项目。

| 阶段 | 主题 | 你会掌握 |
|------|------|----------|
| **01** | 数学与编程基础 | 线代 / 概率 / 微积分 / Python 数据栈 / ML 范式 |
| **02** | 深度学习与 Transformer | 反向传播 / CNN-RNN / Attention / 位置编码 |
| **03** | 预训练 | Tokenizer / Decoder 架构 / Scaling Laws |
| **04** | 微调与对齐 | SFT / LoRA & PEFT / RLHF & DPO |
| **05** | 应用与部署 | KV Cache / 量化 / RAG / Agent |

## 🗂️ 每节的固定结构

每一篇教程都按这个模板写,确保**求职导向**:

- **这节解决什么问题** —— 不讲虚的
- **核心概念 ★** —— 配公式(KaTeX 渲染)
- **为什么这样设计** —— 直觉解释
- **代码:最小实现** —— 可直接跑的 Python
- **⚠️ 易错点 / 面试陷阱** —— 高频踩坑
- **🎯 面试会怎么考** —— 八股 + 手撕 + 深挖
- **📂 简历可写的项目** —— mini 项目建议
- **🔗 延伸阅读** —— 精选论文 / 视频 / 代码库
