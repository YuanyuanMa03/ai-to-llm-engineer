# 第 4 阶段 · 微调与对齐

> 目标:能用 LoRA 微调一个开源模型,理解 RLHF / DPO 在对齐什么。

## 这个阶段解决什么

预训练模型是「博览群书但不会听话」的书呆子。微调让它学会遵循指令,对齐让它符合人类偏好。这是**算法岗最常考、工程中最常做**的环节,也是简历项目的主战场。

## 学习目标

- [ ] 区分预训练 / SFT / 对齐三者的目标和数据
- [ ] 能用 LoRA / QLoRA 在消费级显卡上微调模型
- [ ] 理解 RLHF 的三阶段(奖励模型 + PPO)和它的痛点
- [ ] 说清 DPO 为什么能跳过奖励模型
- [ ] 会构造 SFT 数据集(指令-回答对)
