## 这节解决什么问题

深度学习训练的本质就一句话:**用梯度下降更新参数**。问题来了,一个现代神经网络动辄几百万、几十亿参数,每个参数对损失的影响(梯度)怎么算出来?用定义求 $\frac{f(x+\epsilon)-f(x)}{\epsilon}$ 数值微分?那对一个 10 亿参数的模型就要跑 10 亿次前向,直接爆炸。

**反向传播(Backpropagation)就是把链式法则部署到计算图上的一次工程化**。它只需一次前向 + 一次反向,就能同时算出所有参数的梯度,代价是 $O(\text{参数量})$。这是整个深度学习能"训得动"的根基。面试里只要碰到"训练流程""优化器""梯度消失",根上都通向这一节。

## 核心概念 ★

### 1. 计算图(Computational Graph)

把一个数学表达式拆成一堆**节点(node)**和**边(edge)**。节点是运算(加、乘、激活),边是数据(中间结果,也就是张量)。

例如 $f(x,y)=(x+y)^2$,可以拆成:

```
x ──┐
    ├──(+)──► s ──(²)──► f
y ──┘
```

每个节点都是局部的、可微的小函数。复杂网络 = 大量这种小节点拼起来。

### 2. 前向传播(Forward Pass)

从输入沿边一路算到输出,顺带把每个节点的中间值缓存下来。这些中间值是反向求导的"原料"。

### 3. 反向传播(Backward Pass) = 链式法则的自动化

链式法则是:

$$\frac{d}{dx}f(g(x)) = f'(g(x)) \cdot g'(x)$$

写成多变量版本(局部雅可比相乘):

$$\frac{\partial L}{\partial x_i} = \sum_j \frac{\partial L}{\partial y_j} \cdot \frac{\partial y_j}{\partial x_i}$$

反向传播的关键思路:**从输出端开始,逐节点往回传"上游梯度 $\frac{\partial L}{\partial \text{本节点输出}}$",再和"本节点的局部导数 $\frac{\partial \text{本节点输出}}{\partial \text{本节点输入}}$"相乘,得到本节点输入侧的梯度。** 每个节点只关心自己那一步,完全不需要知道全局结构。

### 4. Value 对象 / micrograd 的核心思想

micrograd(karpathy 的 100 行教学库)用一个 `Value` 类把"数值"和"它的反向逻辑"绑在一起:
- 前向时,新建一个 `Value`,记录它是从哪几个 `Value` 怎么算来的(`_prev`)。
- 调用 `backward()` 时,从输出开始拓扑排序,逐节点调用它注册的 `_backward` 闭包,把梯度累加到上游。

### 5. 激活函数及其梯度

| 激活函数 | 公式 | 导数 |
|---|---|---|
| Sigmoid | $\sigma(x)=\frac{1}{1+e^{-x}}$ | $\sigma'(x)=\sigma(x)(1-\sigma(x))$ |
| Tanh | $\tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}$ | $\tanh'(x)=1-\tanh^2(x)$ |
| ReLU | $\max(0,x)$ | $\begin{cases}1 & x>0\\0 & x\le 0\end{cases}$ |

### 6. 梯度消失 / 爆炸

深层网络里,梯度 = 一堆小于 1(或大于 1)的局部导数连乘:
- 局部导数 $<1$(如 sigmoid 最大 $0.25$)→ 反向越往浅层走,梯度越小 → **梯度消失**,浅层学不动。
- 局部导数 $>1$ → 梯度指数放大 → **梯度爆炸**,数值溢出。

> ✅ **思考一下**:如果全用 ReLU,梯度消失问题就一定不会再出现了吗?提示:ReLU 的导数在 $x\le 0$ 时是多少?

## 为什么这样设计

### 反向模式 vs 正向模式自动微分

| 维度 | 正向模式(Forward Mode) | 反向模式(Reverse Mode) |
|---|---|---|
| 计算方向 | 输入 → 输出 | 输出 → 输入 |
| 一次遍历算出 | 1 个输入的梯度($\frac{\partial y}{\partial x_i}$ 对单个 $i$) | **所有输入的梯度** |
| 对 $n$ 输入 $m$ 输出 | 算全部梯度要 $n$ 次遍历 | 只要 **1 次** |
| 适合什么 | 输入少、输出多($n \ll m$) | 输入多、输出少($n \gg m$),也就是神经网络 |
| 复杂度 | $O(n)\times$ 前向 | $O(1)\times$ 前向(常数倍) |

神经网络正是"几亿个输入参数,1 个标量 Loss"的结构,所以反向模式几乎是唯一选择。这也是 PyTorch `loss.backward()` 一调用、所有参数的 `.grad` 全部填满的原因。

### 为什么需要初始化、不能全 0

如果所有权重初始化为同一个值(包括全 0),同一层的所有神经元前向输出相同、反向梯度相同 → 永远同步更新 → 等价于只有一个神经元,白白浪费容量。这叫**对称性问题**。随机初始化(如 Xavier / He)是为了"打破对称"。

## 代码:最小实现

下面是 micrograd 思想的极简版本,30 行左右,支持 `+ - *`、`relu` 和 `backward`。可以直接跑。

```python
# === 极简 Value 类:micrograd 精简版 ===
class Value:
    def __init__(self, data, _children=(), _op=''):
        self.data = data          # 前向值
        self.grad = 0.0           # 梯度,反向时累加
        # 反向函数:在前向时注册,反向时调用
        self._backward = lambda: None
        self._prev = set(_children)
        self._op = _op

    def __repr__(self):
        return f"Value(data={self.data:.4f}, grad={self.grad:.4f})"

    # ---------- 前向运算:同时注册反向逻辑 ----------
    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), '+')
        def _backward():
            # 加法的局部导数是 1,上游梯度原样传回
            self.grad  += 1.0 * out.grad
            other.grad += 1.0 * out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), '*')
        def _backward():
            # 乘法:对 self 求导得 other,对 other 求导得 self
            self.grad  += other.data * out.grad
            other.grad += self.data * out.grad
        out._backward = _backward
        return out

    def relu(self):
        out = Value(max(0, self.data), (self,), 'relu')
        def _backward():
            self.grad += (1.0 if self.data > 0 else 0.0) * out.grad
        out._backward = _backward
        return out
```

第二步:加一个 `backward()` 入口,做拓扑排序 + 反向传播。

```python
def backward(self):
    """给上方 Value 类补上反向传播入口。"""
    # 1. 拓扑排序:保证父节点先于子节点被处理(反向意义下的"父"=更靠近输出)
    topo = []
    visited = set()
    def build(v):
        if v not in visited:
            visited.add(v)
            for child in v._prev:
                build(child)
            topo.append(v)
    build(self)

    # 2. 起点梯度=1,顺着拓扑序的【逆序】调用每个节点的 _backward
    self.grad = 1.0
    for v in reversed(topo):
        v._backward()

# 浏览器实验台按顺序共享本页变量，把函数挂回上一格定义的类。
Value.backward = backward
```

第三步:跑一个最小例子,验证梯度。

```python
# f(x, y) = relu(x * y + x),手工求 df/dx、df/dy 看对不对
x = Value(2.0)
y = Value(3.0)
z = (x * y) + x       # z = xy + x
out = z.relu()        # out = relu(z),z=8>0,所以 out=8
out.backward()
print(out)            # Value(data=8.0000, grad=1.0000)
print(x)              # Value(data=2.0000, grad=4.0000)  df/dx = y+1 = 4
print(y)              # Value(data=3.0000, grad=2.0000)  df/dy = x   = 2
```

## ⚠️ 易错点 / 面试陷阱

> **梯度梯度要累加,不是赋值。** 一个 `Value` 可能被用在多个地方(例如权重共享),它的梯度是所有使用路径上游梯度的**和**。所以上面代码里都是 `+=`,不是 `=`。面试问"为什么 PyTorch 多次 backward 要 zero_grad",根因就在这。

> **ReLU 不是万能解药。** $x<0$ 区域导数为 0,反向时梯度直接被掐断 → 这个神经元**永久死亡**,不再更新。叫 Dead ReLU。学习率过大或初始化不好时容易出现。Leaky ReLU、GELU 都是为缓解这个问题提出的。

> **梯度消失的本质是"连乘 < 1",不是"层数多"。** 层数多只是放大了这个问题。真正决定的是每层局部导数的量级。所以 BatchNorm 把每层激活拉回均值 0、方差 1,本质是控制激活(从而局部导数)的尺度,避免连乘衰减。

> **数值微分不能代替反向传播。** $\frac{f(x+\epsilon)-f(x)}{\epsilon}$ 看起来"省事",但精度差(截断误差 + 浮点误差),而且对 $n$ 个参数要跑 $n$ 次前向,工程上完全不可行。数值梯度一般只用来**单元测试**反向传播实现是否正确(梯度检查,gradient check)。

## ✅ 课后小测(答案)

**课前小测答案:**
1. 计算图是把数学表达式拆成**节点(运算)**和**边(数据依赖)**的有向无环图。每个节点表示一个基本运算(加、乘、激活),边表示张量的流动。
2. $\frac{dy}{dx}=f'(g(x))\cdot g'(x)$。也就是说,复合函数的导数 = 外层对中间变量的导数 × 中间变量对自变量的导数。
3. 正向模式要 **$n$ 次**遍历才能算出全部 $n$ 个输入的梯度;反向模式只要 **1 次**遍历就能算出所有输入的梯度。神经网络输入(参数)极多、输出(Loss)只有一个,所以反向模式远胜。

**掌握自检:** 如果你能不看笔记回答下面这题,说明这节过关了 ——

> 给定 $f(x,y)=\text{relu}(xy+x)$,$x=2,y=3$,手工算出 $\frac{\partial f}{\partial x}$ 和 $\frac{\partial f}{\partial y}$,并说出反向传播相比正向模式省在了哪里。
>
> **答**:$xy+x=x(y+1)=2\times4=8>0$,relu 原样通过,上游梯度为 1。$\frac{\partial f}{\partial x}=y+1=4$,$\frac{\partial f}{\partial y}=x=2$。反向模式只需一次前向 + 一次反向,就能同时得到对 $x$、$y$ 两个输入的梯度;正向模式要分别从 $x$、$y$ 扫一遍,共两次遍历。当输入维度是几十亿时,这个差距是毁灭性的。
